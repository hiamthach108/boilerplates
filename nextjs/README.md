# Dreon Next.js Boilerplate

Modern App Router boilerplate for Dreon frontend projects.

## Stack

- Next.js 16
- React 19
- TypeScript 6
- Ant Design 6 with App Router registry
- Tailwind CSS 4
- ESLint flat config and Prettier 3
- Storybook 10
- Husky and lint-staged

## Getting Started

```sh
npm install
npm run dev
```

## Scripts

```sh
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
npm run format
npm run storybook
npm run build-storybook
```

## Notes

This template uses npm and commits `package-lock.json` for reproducible installs.
